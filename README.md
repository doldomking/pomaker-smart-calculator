# 🧮 포메이커 스마트 계산기 (Pomaker Smart Calculator)

일반·공학용 계산기와 실시간 각국 환율 변환, 그리고 길이·무게·부피 등 11종 단위 변환 기능을 통합한 올인원 스마트 계산기 웹 애플리케이션입니다.

## ✨ 주요 기능

### 1. 일반 & 공학용 계산기
- 사칙연산, 괄호 연산, 백분율(`%`), 부호 전환(`±`)
- 공학용 함수: 삼각함수(`sin`, `cos`, `tan` 및 역삼각함수), 로그(`log`, `ln`), 제곱근(`√x`, `∛x`), 거듭제곱(`xʸ`, `x²`), 팩토리얼(`n!`), 절댓값(`|x|`), 상수(`π`, `e`)
- 각도 단위 전환 (`DEG` / `RAD`) 및 메모리 기능 (`MC`, `MR`, `M+`, `M-`)
- 계산 기록(History) 자동 저장 및 클릭 시 수식 불러오기
- 계산 결과를 환율 변환기 또는 단위 변환기로 즉시 전달

### 2. 실시간 각국 환율 변환기
- 20개 주요 통화 지원 (`KRW`, `USD`, `JPY`, `EUR`, `CNY`, `GBP`, `TWD`, `HKD`, `SGD`, `THB`, `VND`, `PHP`, `AUD`, `CAD`, `CHF`, `NZD`, `INR`, `MYR`, `IDR`, `MXN`)
- 실시간 환율 API 연동 + 오프라인 캐시/기본 환율 자동 폴백
- 사용자 지정 환율 직접 입력/시뮬레이션 모드 지원
- 한국어 금액 독음 표시 및 주요 14개국 통화 동시 비교표 제공

### 3. 11종 종합 단위 변환기 (한국 전통 단위 포함)
- **길이**: `mm`, `cm`, `m`, `km`, `in`, `ft`, `yd`, `mi`, `해리(nmi)`, `자(척)`, `간`, `리`
- **무게**: `mg`, `g`, `kg`, `t`, `oz`, `lb`, `돈`, `냥`, `근`, `관`
- **부피**: `mL(cc)`, `dL`, `L`, `cm³`, `m³`, `tsp`, `tbsp`, `fl oz`, `cup`, `pt`, `qt`, `gal`, `홉`, `되`, `말`
- **넓이/면적**: `cm²`, `m²`, `평(坪)`, `a`, `ha`, `km²`, `ft²`, `yd²`, `acre`, `단보`, `정보`
- **온도**: 섭씨(`°C`), 화씨(`°F`), 켈빈(`K`)
- **데이터 용량**: `bit`, `B`, `KB`, `MB`, `GB`, `TB`, `PB`, `KiB`, `MiB`, `GiB`, `TiB`
- **속도 / 시간 / 압력 / 에너지(열량) / 연비**: 전체 단위 동시 변환표 지원

## 🚀 실행 방법
별도의 설치 없이 `index.html` 파일을 웹 브라우저에서 열면 바로 실행됩니다.
